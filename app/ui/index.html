How switching works

  1. Graceful shutdown. Steam is asked to close with -shutdown so it finishes Steam Cloud sync and closes downloads cleanly, instead of being force-killed.
  2. Auto-login is repointed. AutoLoginUser in the registry and the MostRecent/AutoLogin flags in loginusers.vdf are set to the target account.
  3. Steam restarts and signs in with the refresh token it already stored for that account — no password, no Steam Guard prompt.

Accounts marked Needs password have no stored token yet. Sign in once with Remember me ticked and every switch after that is instant.

Security

Secrets are sealed with Windows DPAPI and stored in %LOCALAPPDATA%\SteamSwitcher — never in this app's folder, and never anywhere that syncs to the cloud. The switch itself never needs a password.
