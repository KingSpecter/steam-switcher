What a switch does

  1. Closes Steam properly. It runs steam.exe -shutdown so Steam Cloud finishes syncing and downloads stop at a clean point. Steam is only forced closed if it ignores that.
  2. Points auto-login at the account. AutoLoginUser in the registry and the MostRecent / AutoLogin flags in loginusers.vdf are set to it.
  3. Starts Steam again. Steam signs in with the token it saved for that account. No password, no Steam Guard code.

An account marked Needs password has no saved token yet. Sign in to it once with "Remember me" ticked; after that it switches like the others.
